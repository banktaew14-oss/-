# 📊 Sports Analytics & Thai Lottery Predictor

ระบบวิเคราะห์สถิติเพื่อทำนายผลหวยไทย ผลฟุตบอล และผลบาสเกตบอล พัฒนาและทำนายผลโดย Bank Basketman

## 🌟 ฟีเจอร์หลัก (Features)
- **Thai Lottery Predictor:** วิเคราะห์ความถี่สถิติตัวเลขย้อนหลังเพื่อสร้างแนวทางเลขท้าย 2 ตัว และ 3 ตัว
- **Football Match Analytics:** คำนวณความน่าจะเป็นของประตูและผลการแข่งขันฟุตบอล
- **Basketball Analytics:** วิเคราะห์คะแนนต่อเกม (PPG), เกมรับ และคาดการณ์สกอร์สูง/ต่ำสำหรับบาสเกตบอล
